# Recorded Product Requirements Clarifications

- **Provided by:** Product requester
- **Role:** Product decision-maker
- **Date:** 2026-07-22

1. A task must have a non-empty title when it is created.
2. Editing the title is required in the first release.
3. A newly created task appears in TODO.
4. A moved task appears only in its new section.
5. Pending, current, and completed map to TODO, DOING, and DONE respectively.
6. Reopening the application restores every task in its previous section.
