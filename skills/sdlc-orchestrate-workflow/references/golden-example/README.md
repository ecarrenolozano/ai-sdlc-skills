# Progressive Golden Example

1. The developer says, “Continue the project.”
2. The orchestrator locates the repository and checks the workflow trace.
3. If the trace is absent, it routes to bootstrap without exposing an identifier.
4. Otherwise it validates the trace, identifies the highest-priority active gate, and explains the immediate objective.
5. It performs the owning stage through the matching installed skill, preserving every approval boundary.
6. It revalidates the trace and tells the developer what changed, what still needs approval, and what comes next.
