# Progressive Golden Example

1. **Initial state:** A Python repository exists, but `sdlc_docs/trace_workflow.md` does not.
2. **Inspection:** Identify existing source, tests, metadata, and any `sdlc_docs` content.
3. **Proposal:** Show only the missing directories and canonical trace file.
4. **Approval:** Wait for explicit approval before creating local files.
5. **Mutation:** Create missing structure without overwriting existing content.
6. **Validation:** Re-run bootstrap checks and workflow-trace validation.
7. **Handoff:** Tell the developer, in plain language, that project clarification is next and return control to the orchestrator.
