# Browser Task Board Golden Example

This example continues the approved Browser Task Board workflow after Technical foundation is `Complete`.

Planning work: create manual priority guidance for unresolved issues.

Selected implementation work: `US-0001 - Create a task`.

The example demonstrates:

- backlog priority planning under `sdlc_docs/03_implementation/backlog_priority.md`;
- one explicitly selected issue;
- a visible local-change proposal;
- hybrid code-level architecture under `sdlc_docs/02_architecture/`;
- Mermaid diagrams for code-level sequence and class/module design;
- guarded `sdlc_docs/trace_workflow.md` Implementation-row traceability after validation;
- three small TDD cycles;
- unit and integration test placement;
- no architecture, dependency, or foundation change;
- no GitHub issue/project mutation, commit, push, pull request, issue transition, or closure.

Files:

- `backlog_priority.md`: Manual priority guidance example;
- `selected-issue.md`: approved scope;
- `proposal.md`: proposal shown before local writes;
- `code-level.md`: central code-level index example with Mermaid;
- `tdd-execution.md`: observable RED-GREEN-REFACTOR evidence;
- `result.md`: final local result including workflow traceability evidence.
