# Selected Issue

## US-0001 - Create a task

As the board user, I want to create a task so that I can record work to do.

Approved acceptance criteria:

1. A non-blank task title creates a task.
2. A new task starts in `TODO`.
3. A blank title is rejected.
4. The created task is returned through the approved local API boundary.

Out of scope:

- drag-and-drop;
- editing;
- deletion;
- counters;
- collaboration;
- remote deployment.
