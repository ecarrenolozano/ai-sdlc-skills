# Progressive Golden Example

1. **Initial state:** Inspect the required repository artifacts and workflow trace for `h-create-implementation-pull-request`.
2. **Preconditions:** Validate that upstream gates and required evidence are present.
3. **Proposal:** Show the exact intended work and preserve the skill's approval boundaries.
4. **Approval:** Obtain explicit approval whenever the skill requires it.
5. **Execution:** Perform only the permitted local or remote actions.
6. **Validation:** Run the bundled deterministic validators and capture evidence.
7. **Handoff:** Update only owned workflow fields and explain the next developer action.
