# AI SDLC Skills

This site documents the reusable agent skills in this repository.

The skills guide Python projects through a controlled software development lifecycle: project clarification, context formation, requirements, architecture, repository synchronization, technical foundation, implementation, validation, pull request preparation, and release preparation.

The documentation keeps `skills/*/SKILL.md` as the canonical source. Skill pages are generated from the repository so the published documentation explains the workflow without asking maintainers to repeat skill content by hand.

## Start Here

- [Workflow](workflow.md): the lifecycle model and stage order.
- [Skills](skills/index.md): generated catalog with one page per skill.
- [Authoring](authoring.md): conventions for adding or changing skills.
- [Installation](installation.md): how these skills are installed and updated in projects.

## Documentation Model

Hand-written pages explain the system-level concepts that do not belong to one skill. Generated pages explain individual skills by reading their canonical files, process diagrams, validators, references, assets, agents, and golden examples.
